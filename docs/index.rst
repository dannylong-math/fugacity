Fugacity
========

Fugacity is a header-only C++ library for calculating thermodynamic properties
from equations of state. It uses Enzyme automatic differentiation to obtain the
derivatives of Helmholtz-energy models.

This initial documentation site provides a short guide for getting started, an
overview of model implementation, and a reference generated directly from the
public C++ headers.
